# Doctor Personal Website

A responsive, static doctor profile website built with HTML, CSS, Bootstrap 5 and JavaScript.

## Quick customization
Edit `index.html`:
- Doctor name
- Qualification
- Specialty
- Hospital/chamber
- Visiting hours
- Phone / WhatsApp
- Email
- Services
- Address

Replace the photo placeholder with a real professional photo.

## Free deployment
### GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders.
3. Go to Settings → Pages.
4. Select Deploy from branch → main → /root.
5. Save.

### Cloudflare Pages
Connect the GitHub repository and deploy it as a static site. No build command is required.

## Important
The contact form is a demo until connected to a form/email service.
